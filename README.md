# Meu-Plano-IA
Meu Plano IA: Desenvolvido com Google Gemini e Gradio, este projeto cria planos de estudo personalizados. Basta informar seus objetivos, tempo disponível e nível de conhecimento para receber um roteiro completo com módulos, tópicos semanais e sugestões de recursos. Otimize seu aprendizado com a inteligência artificial!
